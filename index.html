Context & Purpose

About the Collection

This collection brings together eight individual projects created to practice HTML, CSS, JavaScript, responsive design, UI design, validation, and application logic.

Rather than relying on heavy frameworks or template bundles, each application was constructed using foundational web standards. This approach solidifies core principles: understanding layout rendering, managing component state in vanilla JavaScript, securing client-side forms, and structuring clean, semantic markup that works reliably across all browsers.

Progressive Complexity

Tasks scale logically from foundational presentation and responsive grids (Level 1) to stateful tools and security mechanisms (Level 2), culminating in an end-to-end interactive platform (Level 3).

Real Browser Standards

Direct implementation of Web Storage for persistence, Web Crypto API for SHA-256 client password hashing, and semantic HTML5 for screen readers.

Reliable Deployment

Every project is organized into modular folders and continuously served via GitHub Pages with automated git-driven deployments.
