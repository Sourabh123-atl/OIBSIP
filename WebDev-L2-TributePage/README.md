# 🕊️ WebDev-L2-TributePage — Dr. A. P. J. Abdul Kalam

**Oasis Infobyte Internship — Web Development & Designing (Level 2, Task 2)**

A visually engaging, biographical tribute page dedicated to Dr. Avul Pakir Jainulabdeen Abdul Kalam (1931–2015), the 11th President of India and pioneer of India's aerospace program.

---

## 📋 Feature Checklist Compliance

- [x] **Page Title & Tagline**: High-impact subject name (*Dr. A. P. J. Abdul Kalam*) and title (*"The Missile Man of India & The People's President"*).
- [x] **Prominent Portrait Image**: Prominent portrait framing with biographical metadata.
- [x] **In-Depth Biography Section**: 4 original structured paragraphs detailing his early upbringing in Rameswaram, aerospace innovations at ISRO & DRDO, landmark presidency, and teaching legacy.
- [x] **Chronological Timeline**: Interactive milestone tree marking key career dates (1960 to 2015).
- [x] **Distinct Quote Block**: Hero quote callout with oversized quotation styling and author citation from *Wings of Fire*.
- [x] **Multiple Background Palettes**: Explores 3+ distinct background tones across sections (Midnight Slate Navy, Warm Light Parchment, Indigo Violet, and Deep Charcoal).
- [x] **Font Pairing Hierarchy**: Classical serif (*Playfair Display*) for headings and modern sans-serif (*Plus Jakarta Sans*) for readable body copy.
- [x] **Responsive Layout**: Fluid CSS Grid and Flexbox responsive structure.

---

## 🛠️ Tech Stack
- **HTML5**: Semantic tags (`<header>`, `<main>`, `<article>`, `<blockquote>`, `<cite>`, `<footer>`).
- **CSS3**: CSS Grid, Flexbox, Custom Properties, Typography styling, IntersectionObserver animations.
- **JavaScript**: Smooth scroll navigation, scroll reveal effects.

---
