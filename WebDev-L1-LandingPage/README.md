# 🚀 WebDev-L1-LandingPage — NovaCloud AI

**Oasis Infobyte Internship — Web Development & Designing (Level 1, Task 1)**

An ultra-modern, high-converting product landing page for **NovaCloud AI**, an autonomous edge cloud infrastructure platform.

---

## 📋 Feature Checklist Compliance

- [x] **Fixed / Sticky Navigation Bar**: Frosted glass sticky header with active navigation links, brand logo, and call-to-action buttons.
- [x] **Hero Section**: High-impact headline, subheadline, interactive badge, CTA buttons, and live performance metrics strip.
- [x] **Distinct Content Sections**:
  - `Features Grid`: Core capabilities, predictive auto-scaling, zero-trust edge security, and neural observability.
  - `Architecture & Code Showcase`: Interactive terminal mockup and step-by-step developer deployment flow.
  - `Testimonials Section`: Social proof cards with star ratings and verified executive quotes.
  - `Tiered Pricing Table`: Starter, Pro, and Enterprise pricing cards with highlighted popular tier.
- [x] **Footer**: Comprehensive site links, newsletter subscription, and social media channels.
- [x] **Consistent Colour Palette**: Curated dark palette (`#0a0d14`), indigo gradients (`#6366f1`), and emerald highlights.
- [x] **Responsive Layout**: Fluid CSS Grid and Flexbox layouts tested across mobile (<768px), tablet (992px), and desktop (1200px+).
- [x] **No Element Overlap**: Precise CSS box-sizing, intentional margins, and responsive line heights.
- [x] **Typography**: Google Fonts (*Outfit* for headings, *Plus Jakarta Sans* for body text).

---

## 🛠️ Tech Stack
- **HTML5**: Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: Custom properties, Glassmorphism, CSS Grid & Flexbox, micro-animations.
- **Vanilla JavaScript**: Mobile drawer toggle, scroll-spy nav indicator, newsletter validation.
