Biographical Background

About Me

I am a software engineering student and developer participating in the Oasis Infobyte Student Internship Program (OIBSIP). My focus centers on architecting clean, responsive user interfaces, robust client-side state models, and performant web workflows.

During this internship, I engineered eight comprehensive web applications spanning foundational layout design, calculation utilities, client-side SHA-256 cryptographic authentication, and full-featured ordering platforms.

I place high value on craftsmanship: writing self-documenting code, minimizing bundle footprints by leveraging native web platform APIs, and ensuring every design is thoroughly accessible across mobile and desktop devices.
